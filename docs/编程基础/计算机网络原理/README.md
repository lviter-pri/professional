# 计算机网络专区

计算机网络是连接不同地理位置的计算机和设备的通信系统。理解网络原理是开发网络应用的基础。

## 一、网络概述

### 1.1 网络分类

| 分类 | 范围 | 特点 |
|------|------|------|
| **局域网（LAN）** | 较小范围 | 高速、低延迟 |
| **城域网（MAN）** | 城市范围 | 中等规模 |
| **广域网（WAN）** | 跨地域 | 覆盖广、延迟较高 |
| **互联网（Internet）** | 全球范围 | 最大的网络 |

### 1.2 网络性能指标

| 指标 | 说明 |
|------|------|
| **带宽** | 传输速率（bps） |
| **延迟** | 数据传输时间 |
| **吞吐量** | 单位时间传输量 |
| **丢包率** | 丢失数据包比例 |
| **抖动** | 延迟变化 |

## 二、OSI七层参考模型

### 2.1 分层结构

| 层级 | 名称 | 功能 | 设备 |
|------|------|------|------|
| **7** | 应用层 | 提供应用服务 | 主机 |
| **6** | 表示层 | 数据格式转换 | 主机 |
| **5** | 会话层 | 建立管理会话 | 主机 |
| **4** | 传输层 | 端到端传输 | 主机 |
| **3** | 网络层 | 路由选择 | 路由器 |
| **2** | 数据链路层 | 帧传输 | 交换机 |
| **1** | 物理层 | 比特传输 | 网卡、网线 |

### 2.2 数据封装过程

```
应用层数据 → 表示层 → 会话层 → 传输层（分段）→ 
网络层（分组）→ 数据链路层（帧）→ 物理层（比特）
```

## 三、TCP/IP协议栈

### 3.1 TCP/IP四层模型

| 层级 | 协议 | 功能 |
|------|------|------|
| **应用层** | HTTP、FTP、DNS、SMTP | 应用协议 |
| **传输层** | TCP、UDP | 端到端传输 |
| **网络层** | IP、ICMP、ARP | 路由转发 |
| **网络接口层** | Ethernet、Wi-Fi | 物理传输 |

### 3.2 TCP协议

**特点：**
- 面向连接
- 可靠传输（三次握手、确认重传）
- 流量控制（滑动窗口）
- 拥塞控制（慢启动、拥塞避免）

**三次握手：**
```
Client → Server: SYN
Server → Client: SYN+ACK  
Client → Server: ACK
```

**四次挥手：**
```
Client → Server: FIN
Server → Client: ACK
Server → Client: FIN
Client → Server: ACK
```

### 3.3 UDP协议

**特点：**
- 无连接
- 不可靠传输
- 低延迟
- 适用于实时应用（视频、语音）

### 3.4 IP协议

**IP地址分类：**

| 类别 | 范围 | 用途 |
|------|------|------|
| **A类** | 1-126 | 大型网络 |
| **B类** | 128-191 | 中型网络 |
| **C类** | 192-223 | 小型网络 |
| **D类** | 224-239 | 组播 |
| **E类** | 240-255 | 保留 |

## 四、HTTP协议

### 4.1 HTTP特点

- 无状态协议
- 基于TCP
- 明文传输

### 4.2 HTTP方法

| 方法 | 语义 | 幂等 |
|------|------|------|
| **GET** | 获取资源 | 是 |
| **POST** | 创建资源 | 否 |
| **PUT** | 更新资源 | 是 |
| **DELETE** | 删除资源 | 是 |
| **PATCH** | 部分更新 | 否 |

### 4.3 HTTP状态码

| 类别 | 范围 | 说明 |
|------|------|------|
| **1xx** | 100-199 | 信息性响应 |
| **2xx** | 200-299 | 成功 |
| **3xx** | 300-399 | 重定向 |
| **4xx** | 400-499 | 客户端错误 |
| **5xx** | 500-599 | 服务器错误 |

### 4.4 HTTPS

**HTTPS = HTTP + TLS/SSL**

**优势：**
- 数据加密
- 身份认证
- 完整性保护
