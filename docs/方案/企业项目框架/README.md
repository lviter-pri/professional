# 企业项目框架

企业项目框架是构建大型分布式系统的基础，涉及多种技术栈和架构模式。本目录涵盖了项目研发基础规范和最佳实践。

## 相关文档

有关分布式与微服务相关的内容，请参阅：[分布式与微服务](../../分布式与微服务/README.md)

## 一、项目研发基础规范

### 1.1 代码结构规范

合理的代码组织是项目可维护性的基础，定义了项目的包结构和代码组织原则。

### 1.2 Git 分支管理

规范的分支策略确保团队协作顺畅，包括分支命名规范、合并流程和代码审查要求。

### 1.3 MapStruct

对象映射工具，简化 DTO 转换，提高开发效率。

### 1.4 日志规范

统一的日志格式和规范，便于日志收集、分析和问题排查。
