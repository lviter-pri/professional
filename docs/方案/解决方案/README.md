## 二、典型解决方案

### 2.1 分布式事务解决方案

分布式事务是微服务架构中的核心难题，常见方案：

- **TCC模式**：Try-Confirm-Cancel，业务层实现
- **Saga模式**：事件驱动，补偿操作
- **AT模式**：自动事务，基于XA协议
- **消息事务**：可靠消息最终一致性

### 2.2 延迟队列解决方案

延迟队列用于处理需要延迟执行的任务：

- **Redis ZSet**：基于分数排序
- **RabbitMQ延迟队列**：死信队列实现
- **RocketMQ延迟消息**：原生支持

### 2.3 分库分表方案

当单表数据量过大时需要分库分表：

- **水平拆分**：按行拆分（如按用户ID哈希）
- **垂直拆分**：按列拆分（如分离冷热数据）
- **ShardingSphere**：分库分表中间件

## 三、问题排查指南

### 3.1 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| **Transaction rolled back because it has been marked as rollback-only** | 嵌套事务中内部事务回滚 | 检查事务传播配置 |
| **数据库连接池耗尽** | 连接未正确释放 | 使用try-with-resources |
| **慢查询** | 索引缺失或SQL不合理 | 优化SQL和索引 |

### 3.2 排查步骤

1. **定位问题**：日志分析、监控告警
2. **分析原因**：代码审查、性能分析
3. **制定方案**：优化方案、回滚计划
4. **实施验证**：灰度发布、回归测试
