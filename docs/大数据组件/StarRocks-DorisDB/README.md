# StarRocks

StarRocks是一个新一代MPP（大规模并行处理）分析型数据库，源自Apache Doris，专注于实时数据分析场景。

## 一、StarRocks概述

### 1.1 核心特点

- **高性能**：向量化引擎、列式存储、智能优化器
- **实时性**：支持实时数据摄入，秒级查询响应
- **弹性扩展**：在线扩容缩容，不影响业务
- **易用性**：标准SQL兼容，丰富的生态集成
- **高可用**：多副本机制，自动故障恢复

### 1.2 架构设计

```
┌─────────────────────────────────────────────────────┐
│              Frontend（FE）层                      │
│  - SQL解析优化  - 元数据管理  - 查询调度            │
├─────────────────────────────────────────────────────┤
│              Backend（BE）层                       │
│  - 数据存储  - 查询执行  - 数据导入                │
├─────────────────────────────────────────────────────┤
│                    存储层                          │
│  - 列式存储  - 索引结构  - 副本管理                │
└─────────────────────────────────────────────────────┘
```

### 1.3 适用场景

| 场景 | 说明 |
|------|------|
| **实时数据分析** | 秒级延迟的OLAP分析 |
| **数据仓库** | 大规模数据存储和分析 |
| **Ad-hoc查询** | 灵活的即席查询 |
| **报表分析** | 复杂报表生成 |
| **用户行为分析** | 海量日志分析 |

## 二、核心概念

### 2.1 数据模型

| 模型 | 特点 | 适用场景 |
|------|------|----------|
| **明细模型** | 存储原始数据 | 数据分析、追溯 |
| **聚合模型** | 预聚合数据 | 报表统计 |
| **更新模型** | 支持数据更新 | 实时数据同步 |
| **主键模型** | 主键去重 | 实时数据更新 |

### 2.2 存储结构

- **列式存储**：按列存储，适合分析场景
- **索引**：前缀索引、ZoneMap、Bitmap索引
- **分区**：支持范围分区、列表分区、哈希分区
- **分桶**：数据分片，并行处理

### 2.3 数据导入

| 方式 | 特点 | 适用场景 |
|------|------|----------|
| **Broker Load** | 批量导入 | 大批量历史数据 |
| **Stream Load** | 流式导入 | 实时数据 |
| **Routine Load** | 持续导入 | Kafka等消息队列 |
| **Insert** | 单行/批量插入 | 少量数据 |

## 三、性能优化

### 3.1 查询优化

- **谓词下推**：将过滤条件推到存储层
- **聚合下推**：在BE层完成聚合
- **列式裁剪**：只读取需要的列
- **智能缓存**：中间结果缓存

### 3.2 数据组织

- **合理分区**：按时间分区，减少扫描范围
- **前缀索引**：优化等值查询
- **物化视图**：预计算热点查询
- **数据排序**：按查询频率排序

### 3.3 配置调优

- **并行度设置**：根据集群规模调整
- **内存分配**：合理分配查询内存
- **IO优化**：SSD存储、RAID配置

### 4.2 查询集成

## 五、运维管理

### 5.1 集群部署

- **多节点部署**：生产环境，FE/BE分离
