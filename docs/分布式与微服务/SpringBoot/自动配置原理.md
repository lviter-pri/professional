# SpringBoot自动配置原理

## 一、自动配置的核心

SpringBoot自动配置的核心是`@EnableAutoConfiguration`注解，它会：
- 扫描classpath下的自动配置类
- 根据条件决定是否启用配置
- 自动注册Bean

## 二、自动配置流程

```mermaid
flowchart TD
    A[启动应用] --> B[@EnableAutoConfiguration]
    B --> C[SpringFactoriesLoader]
    C --> D[加载spring.factories]
    D --> E[获取自动配置类列表]
    E --> F{遍历配置类}
    F --> G[@Conditional条件判断]
    G -->|满足条件| H[注册Bean]
    G -->|不满足| I[跳过]
    F -->|完成| J[自动配置完成]
```

## 三、关键组件

### 3.1 SpringFactoriesLoader

```java
// 加载META-INF/spring.factories文件
List<String> configurations = SpringFactoriesLoader.loadFactoryNames(
    EnableAutoConfiguration.class, classLoader);
```

### 3.2 spring.factories文件格式

```properties
org.springframework.boot.autoconfigure.EnableAutoConfiguration=\
org.springframework.boot.autoconfigure.web.servlet.WebMvcAutoConfiguration,\
org.springframework.boot.autoconfigure.jdbc.DataSourceAutoConfiguration,\
org.springframework.boot.autoconfigure.orm.jpa.HibernateJpaAutoConfiguration
```

## 四、条件注解详解

### 4.1 常用条件注解

| 注解 | 条件 | 示例 |
|------|------|------|
| `@ConditionalOnClass` | 类存在 | `@ConditionalOnClass(DataSource.class)` |
| `@ConditionalOnMissingClass` | 类不存在 | `@ConditionalOnMissingClass("com.mysql.cj.jdbc.Driver")` |
| `@ConditionalOnBean` | Bean存在 | `@ConditionalOnBean(DataSource.class)` |
| `@ConditionalOnMissingBean` | Bean不存在 | `@ConditionalOnMissingBean(JdbcTemplate.class)` |
| `@ConditionalOnProperty` | 配置属性满足 | `@ConditionalOnProperty(prefix="spring.datasource", name="url")` |
| `@ConditionalOnWebApplication` | Web应用 | - |
| `@ConditionalOnNotWebApplication` | 非Web应用 | - |

### 4.2 条件注解组合使用

```java
@Configuration
@ConditionalOnClass({DataSource.class, EmbeddedDatabaseType.class})
@ConditionalOnMissingBean(type = "io.r2dbc.spi.ConnectionFactory")
@EnableConfigurationProperties(DataSourceProperties.class)
public class DataSourceAutoConfiguration {
    // 配置内容
}
```

## 五、自动配置示例

### 5.1 DataSource自动配置

```java
@Configuration
public class DataSourceAutoConfiguration {
    
    @Bean
    @ConditionalOnMissingBean
    @ConditionalOnProperty(name = "spring.datasource.type")
    public DataSource dataSource(DataSourceProperties properties) {
        return properties.initializeDataSourceBuilder().build();
    }
}
```

### 5.2 WebMvc自动配置

```java
@Configuration
@ConditionalOnWebApplication(type = Type.SERVLET)
@ConditionalOnClass({Servlet.class, DispatcherServlet.class, WebMvcConfigurer.class})
@ConditionalOnMissingBean(WebMvcConfigurationSupport.class)
@AutoConfigureOrder(Ordered.HIGHEST_PRECEDENCE + 10)
public class WebMvcAutoConfiguration {
    // 配置内容
}
```

## 六、自定义自动配置

### 6.1 创建配置类

```java
@Configuration
@ConditionalOnClass(MyService.class)
@EnableConfigurationProperties(MyProperties.class)
public class MyAutoConfiguration {
    
    @Bean
    @ConditionalOnMissingBean
    public MyService myService(MyProperties properties) {
        return new MyService(properties);
    }
}
```

### 6.2 注册到spring.factories

```properties
org.springframework.boot.autoconfigure.EnableAutoConfiguration=\
com.example.autoconfigure.MyAutoConfiguration
```

## 七、自动配置调试

### 7.1 查看自动配置报告

```bash
# 启动时添加调试参数
java -jar myapp.jar --debug
```

### 7.2 排除自动配置

```java
@SpringBootApplication(exclude = {DataSourceAutoConfiguration.class})
public class Application {
    // ...
}
```

```yaml
spring:
  autoconfigure:
    exclude:
      - org.springframework.boot.autoconfigure.jdbc.DataSourceAutoConfiguration
```

## 八、总结

自动配置的核心流程：
1. `@EnableAutoConfiguration`触发
2. `SpringFactoriesLoader`加载配置类
3. 条件注解判断是否启用
4. 自动注册Bean到容器

**优势**：
- 开箱即用
- 约定优于配置
- 高度可定制
- 灵活的条件装配
