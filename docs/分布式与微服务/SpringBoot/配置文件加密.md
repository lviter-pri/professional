# SpringBoot配置文件加密

## 一、为什么需要加密

在SpringBoot应用中，配置文件通常包含敏感信息：
- 数据库密码
- API密钥
- 第三方服务凭证

如果这些信息明文存储，会带来安全风险。

## 二、常用加密方案

### 2.1 Jasypt加密

**添加依赖：**

```xml
<dependency>
    <groupId>com.github.ulisesbocchio</groupId>
    <artifactId>jasypt-spring-boot-starter</artifactId>
    <version>3.0.4</version>
</dependency>
```

**配置加密密钥：**

```yaml
# application.yml
jasypt:
  encryptor:
    password: ${JASYPT_ENCRYPTOR_PASSWORD}
    algorithm: PBEWITHHMACSHA512ANDAES_256
```

**加密命令：**

```bash
# 使用Jasypt CLI工具
java -cp jasypt-1.9.3.jar org.jasypt.intf.cli.JasyptPBEStringEncryptionCLI \
  input="mydatabasepassword" \
  password=mySecretKey \
  algorithm=PBEWITHHMACSHA512ANDAES_256
```

**在配置文件中使用加密值：**

```yaml
spring:
  datasource:
    password: ENC(加密后的字符串)
```

### 2.2 Spring Cloud Config加密

**配置密钥库：**

```yaml
encrypt:
  key-store:
    location: classpath:server.jks
    password: myPassword
    alias: myAlias
    secret: mySecret
```

**加密API：**

```bash
# 加密
curl -X POST http://localhost:8888/encrypt -d mysecret

# 解密
curl -X POST http://localhost:8888/decrypt -d encryptedValue
```

### 2.3 自定义加密

```java
@Component
public class CustomEncryptor {
    
    private static final String SECRET_KEY = "my-secret-key";
    
    public String encrypt(String plainText) {
        // 实现加密逻辑
        return encryptedValue;
    }
    
    public String decrypt(String encryptedText) {
        // 实现解密逻辑
        return plainText;
    }
}
```

## 三、最佳实践

| 方案 | 适用场景 | 安全性 |
|------|----------|--------|
| Jasypt | 单机应用 | 中 |
| Spring Cloud Config | 微服务架构 | 高 |
| 自定义加密 | 特殊需求 | 可定制 |

**注意事项：**
- 加密密钥不应存储在代码仓库中
- 使用环境变量或密钥管理服务
- 定期轮换密钥
