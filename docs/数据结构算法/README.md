# 数据结构与算法

数据结构和算法是计算机科学的基础，是编写高效程序的关键。本目录涵盖常用数据结构和经典算法。

## 一、数据结构概述

### 1.1 什么是数据结构

数据结构是计算机存储、组织数据的方式，它包含以下几个方面：

- **逻辑结构**：数据元素之间的关系
- **存储结构**：数据在计算机中的存储方式
- **运算**：对数据的操作（插入、删除、查找等）

### 1.2 数据结构分类

| 分类 | 特点 | 代表 |
|------|------|------|
| **线性结构** | 元素有序排列 | 数组、链表、栈、队列 |
| **非线性结构** | 元素之间有多对多关系 | 树、图 |
| **哈希结构** | 基于哈希函数 | 哈希表 |

## 二、常用数据结构

### 2.1 数组（Array）

**特点：**
- 连续内存空间
- 随机访问O(1)
- 插入删除O(n)

**适用场景：**
- 数据量固定
- 频繁访问，较少插入删除

### 2.2 链表（Linked List）

**特点：**
- 非连续内存空间
- 顺序访问O(n)
- 插入删除O(1)

**类型：**
- 单链表
- 双链表
- 循环链表

### 2.3 栈（Stack）

**特点：**
- 后进先出（LIFO）
- 常用操作：push、pop、peek

**应用场景：**
- 表达式求值
- 括号匹配
- 函数调用栈

### 2.4 队列（Queue）

**特点：**
- 先进先出（FIFO）
- 常用操作：enqueue、dequeue

**类型：**
- 普通队列
- 双端队列（Deque）
- 优先级队列

### 2.5 哈希表（Hash Table）

**特点：**
- 基于哈希函数
- 平均O(1)查找
- 可能产生哈希冲突

**解决冲突方法：**
- 链地址法
- 开放地址法
- 再哈希法

### 2.6 树（Tree）

**特点：**
- 层次结构
- 每个节点有零个或多个子节点

**常用树类型：**
- 二叉树
- 二叉搜索树（BST）
- AVL树（自平衡）
- 红黑树
- B/B+树

### 2.7 图（Graph）

**特点：**
- 由顶点和边组成
- 表示多对多关系

**类型：**
- 有向图/无向图
- 加权图/无权图
- 稀疏图/稠密图

## 三、算法概述

### 3.1 什么是算法

算法是解决特定问题的一组清晰指令，具有以下特性：

- **有穷性**：有限步骤结束
- **确定性**：每个步骤唯一
- **可行性**：可执行
- **输入输出**：有明确的输入输出

### 3.2 算法复杂度

**时间复杂度：**

| 复杂度 | 符号 | 说明 |
|--------|------|------|
| 常数 | O(1) | 固定时间 |
| 对数 | O(log n) | 二分查找 |
| 线性 | O(n) | 遍历 |
| 线性对数 | O(n log n) | 快速排序 |
| 平方 | O(n²) | 冒泡排序 |
| 指数 | O(2ⁿ) | 递归斐波那契 |

**空间复杂度：**
- O(1)：常数空间
- O(n)：线性空间
- O(n²)：平方空间

## 四、常用算法

### 4.1 排序算法

| 算法 | 平均复杂度 | 空间复杂度 | 稳定性 |
|------|-----------|-----------|--------|
| **冒泡排序** | O(n²) | O(1) | 稳定 |
| **选择排序** | O(n²) | O(1) | 不稳定 |
| **插入排序** | O(n²) | O(1) | 稳定 |
| **快速排序** | O(n log n) | O(log n) | 不稳定 |
| **归并排序** | O(n log n) | O(n) | 稳定 |
| **堆排序** | O(n log n) | O(1) | 不稳定 |

### 4.2 查找算法

| 算法 | 复杂度 | 适用场景 |
|------|--------|----------|
| **顺序查找** | O(n) | 无序数据 |
| **二分查找** | O(log n) | 有序数组 |
| **哈希查找** | O(1) | 哈希表 |
| **二叉搜索树查找** | O(log n) | BST |

### 4.3 图算法

| 算法 | 用途 |
|------|------|
| **BFS** | 最短路径（无权图） |
| **DFS** | 深度遍历、连通性检测 |
| **Dijkstra** | 最短路径（正权图） |
| **Floyd-Warshall** | 所有节点对最短路径 |
| **Prim** | 最小生成树 |
| **Kruskal** | 最小生成树 |

### 4.4 动态规划

**核心思想：**
- 将问题分解为子问题
- 保存子问题的解避免重复计算
- 从底向上求解

**适用条件：**
- 最优子结构
- 重叠子问题

## 五、学习建议

### 5.1 学习路径

1. **基础数据结构**：数组、链表、栈、队列
2. **高级数据结构**：树、图、哈希表
3. **基础算法**：排序、查找
4. **高级算法**：动态规划、贪心、图算法
5. **实战练习**：LeetCode、面试题

### 5.2 练习方法

- 理解问题
- 分析复杂度
- 手写代码
- 测试边界情况
